FINDING / 2026-09-06

Governor and KV tuning more than doubled MoE decode

A powersave CPU governor and f16 KV cache were costing more than half of K2-Horizon decode speed on the DDR4 Unraid box; the fixes took it from 9.5 to 22.1 tok/s with no quality loss.

The first K2-Horizon MoVA 36B-A4B throughput sweep on the Unraid box measured about 9.5 tok/s, barely above the much smaller dense model previously benchmarked there. The model was IQ3_XXS with CPU-offloaded experts, so the expectation was memory-bandwidth bound but not this slow.

Three changes explained the gap. The CPU frequency governor was set to powersave; forcing performance raised clocks under bursty MoE expert streaming. The KV cache moved from f16 to q8_0, halving cache bandwidth for negligible quality cost. Loading switched to mlock plus mmap so streamed expert weights stay resident.

The re-run measured 22.2 / 22.1 / 22.1 tok/s across short, reasoning, and code prompt classes: 2.3 times the baseline from configuration alone. The same q8_0 KV and mlock settings carried to the Mac build, where the model runs fully in unified memory at about 54 tok/s.

Speculative decoding was also evaluated and ruled out for this model: no MTP draft model exists for the architecture, and n-gram drafting is a poor fit for CPU-offloaded MoE where expert streaming, not logits, is the bottleneck. This matches the earlier Flash-Next MTP finding.
